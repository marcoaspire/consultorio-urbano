
# Objetivo del proyecto

Construir una plataforma web minimalista, ágil y de uso privado que permita centralizar, consultar y presentar análisis geoespaciales mediante una galería interactiva, facilitando la inspección visual directa entre tomas temporales (comparador antes/después) y la revisión de reportes técnicos en PDF, sin la sobrecarga operativa de un visor SIG tradicional, Tailwind.

El proyecto ya está creado y con tailwind instalado, pero sin estilos ni funcionalidades.
